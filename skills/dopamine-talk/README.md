# dopamine-talk

Communication-style skill for coding agents that cuts file-path narration, boilerplate padding, trailing hedging disclaimers, and unasked critic-gate suggestions.

## When to Use

- Asking an agent to explain a change in plain workflow terms instead of reciting touched files and `if`-branches.
- Brainstorming product or engineering improvements without default reviewer-gate boilerplate.
- Requesting grounded theoretical `Before -> After` estimates without trailing disclaimer paragraphs.
